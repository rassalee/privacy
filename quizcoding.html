KEBIJAKAN PRIVASI Aplikasi Quiz Coding menghargai dan melindungi privasi pengguna. Aplikasi ini tidak mengumpulkan, menyimpan, memproses, atau membagikan data pribadi pengguna dalam bentuk apa pun. Seluruh fitur aplikasi dapat digunakan sepenuhnya secara offline tanpa memerlukan login, akun, atau koneksi internet. Seluruh data permainan seperti skor, level, dan progres disimpan secara lokal di perangkat pengguna dan tidak dikirim ke server mana pun. Aplikasi ini tidak: Mengumpulkan data pribadi pengguna Mengakses kontak, lokasi, kamera, atau mikrofon Menggunakan layanan pihak ketiga seperti iklan, analitik, atau pelacakan Membagikan data kepada pihak ketiga mana pun Apabila di masa mendatang terdapat perubahan terkait pengumpulan atau penggunaan data, kebijakan privasi ini akan diperbarui sesuai dengan ketentuan yang berlaku.
