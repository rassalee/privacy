Toolbox Super

Kebijakan Privasi

Terakhir diperbarui: 18 September 2026

Toolbox Super menghargai privasi setiap pengguna. Kebijakan Privasi ini menjelaskan bagaimana informasi dapat dikumpulkan, digunakan, disimpan, dan dilindungi ketika Anda menggunakan aplikasi Toolbox Super.

Dengan menggunakan Toolbox Super, Anda memahami praktik yang dijelaskan dalam Kebijakan Privasi ini.

1 Informasi yang Dapat Dikumpulkan

Toolbox Super dapat memproses atau mengumpulkan informasi tertentu sesuai dengan fitur yang digunakan, antara lain:

  • Informasi akun, seperti nama, alamat email, foto profil, atau pengenal akun apabila pengguna memilih untuk membuat atau masuk ke akun.
  • Informasi perangkat dan aplikasi yang diperlukan untuk menjalankan fitur tertentu.
  • Informasi jaringan, seperti alamat IP, informasi koneksi, DNS, gateway, Wi-Fi, atau informasi jaringan lainnya yang diperlukan ketika menggunakan Network Tools.
  • File, gambar, dokumen, atau konten lain yang dipilih sendiri oleh pengguna ketika menggunakan File Tools, Image Tools, Document Tools, Converter, atau fitur terkait.
  • Informasi penggunaan aplikasi, seperti fitur yang digunakan, error, crash, dan informasi diagnostik apabila layanan analitik atau crash reporting digunakan.
  • File dan metadata yang secara sengaja disimpan pengguna pada Toolbox Drive apabila layanan tersebut tersedia.

Toolbox Super tidak akan dengan sengaja mengakses file atau informasi pribadi yang tidak diperlukan oleh fitur yang sedang digunakan.

2 Izin Perangkat

Beberapa fitur Toolbox Super mungkin membutuhkan izin Android tertentu, seperti:

  • Kamera — untuk scanner, QR/barcode, atau fitur berbasis kamera.
  • Foto, video, atau file — untuk membuka, membuat, mengonversi, dan menyimpan file yang dipilih pengguna.
  • Jaringan dan internet — untuk Network Tools dan layanan online.
  • Notifikasi — untuk memberikan pemberitahuan tertentu.
  • Lokasi — hanya apabila diperlukan oleh fitur Android tertentu, termasuk informasi Wi-Fi yang pada versi Android tertentu dilindungi oleh izin lokasi.

Izin hanya diminta ketika diperlukan oleh fitur terkait, sejauh memungkinkan. Pengguna dapat mengubah izin aplikasi melalui pengaturan Android.

3 Pemrosesan File

Beberapa fitur Toolbox Super dapat memproses file secara lokal pada perangkat.

Apabila sebuah fitur bekerja sepenuhnya secara lokal, file tidak perlu dikirim ke server Toolbox Super.

Untuk fitur yang membutuhkan layanan cloud atau server, aplikasi dapat mengirim data yang diperlukan untuk menjalankan fitur tersebut. Apabila pemrosesan cloud digunakan, pengguna akan diberi informasi yang sesuai apabila diperlukan.

4 Toolbox Drive

Jika pengguna memilih menggunakan Toolbox Drive, file yang dipilih untuk disimpan ke Toolbox Drive dapat diunggah dan disimpan pada layanan penyimpanan cloud yang digunakan Toolbox Super.

File tidak akan dimasukkan ke Toolbox Drive hanya karena file tersebut terdapat pada perangkat pengguna. Pengunggahan dilakukan melalui tindakan atau fitur yang dipilih pengguna.

Pengguna bertanggung jawab atas file dan konten yang disimpan pada akun Toolbox Drive miliknya.

5 Network Tools

Toolbox Super menyediakan berbagai alat diagnostik jaringan seperti network scanner, port scanner, ping, DNS lookup, dan alat jaringan lainnya.

Untuk menjalankan fitur tersebut, aplikasi dapat memproses alamat IP, hostname, port, informasi perangkat jaringan, dan informasi teknis lainnya.

Informasi tersebut digunakan untuk menjalankan fungsi yang diminta pengguna.

Pengguna bertanggung jawab untuk menggunakan Network Tools hanya pada perangkat, sistem, atau jaringan yang dimiliki atau yang telah memberikan izin untuk diperiksa.

6 Penggunaan Informasi

Informasi yang diproses atau dikumpulkan dapat digunakan untuk:

  • Menyediakan fungsi aplikasi.
  • Menyimpan dan mengelola akun pengguna.
  • Menjalankan Toolbox Drive.
  • Menyimpan preferensi aplikasi.
  • Memperbaiki bug dan meningkatkan performa.
  • Menjaga keamanan layanan.
  • Mencegah penyalahgunaan.
  • Memberikan dukungan kepada pengguna.
  • Memenuhi kewajiban hukum yang berlaku.

7 Berbagi Data

Toolbox Super tidak menjual informasi pribadi pengguna.

Data tertentu dapat diproses oleh penyedia layanan pihak ketiga yang diperlukan untuk menjalankan aplikasi, misalnya:

  • Penyedia hosting atau cloud storage.
  • Sistem autentikasi.
  • Layanan analitik dan crash reporting.
  • Infrastruktur jaringan.
  • Layanan lain yang secara jelas digunakan oleh fitur tertentu.

Penggunaan layanan pihak ketiga dapat tunduk pada kebijakan privasi masing-masing penyedia.

8 Keamanan Data

Kami berupaya menggunakan langkah teknis dan organisasi yang wajar untuk melindungi data pengguna.

Namun, tidak ada sistem elektronik, jaringan, atau penyimpanan online yang dapat dijamin 100% aman.

Pengguna juga bertanggung jawab menjaga keamanan perangkat dan informasi akun miliknya.

9 Penyimpanan dan Penghapusan Data

Data disimpan selama diperlukan untuk menyediakan layanan atau memenuhi kewajiban yang berlaku.

Jika fitur akun tersedia, pengguna dapat diberikan pilihan untuk menghapus akun dan data terkait sesuai dengan fungsi yang tersedia dan ketentuan yang berlaku.

File lokal yang dibuat menggunakan Toolbox Super tetap berada pada perangkat atau lokasi penyimpanan yang dipilih pengguna sampai pengguna menghapusnya.

10 Privasi Anak

Toolbox Super tidak dimaksudkan untuk secara sengaja mengumpulkan informasi pribadi anak di bawah usia minimum yang ditentukan oleh hukum yang berlaku tanpa dasar atau persetujuan yang diperlukan.

11 Tautan dan Layanan Pihak Ketiga

Toolbox Super dapat berinteraksi dengan situs web, server, API, atau layanan pihak ketiga.

Kami tidak mengendalikan praktik privasi layanan pihak ketiga tersebut.

12 Perubahan Kebijakan Privasi

Kebijakan Privasi ini dapat diperbarui untuk menyesuaikan perubahan fitur, teknologi, peraturan, atau layanan Toolbox Super.

Tanggal pembaruan terbaru akan ditampilkan pada bagian atas kebijakan ini.
